КАК ВЫЛОЖИТЬ ЭТУ РАБОТУ НА GITHUB PAGES
=======================================

Делается один раз, минут за десять. Ничего устанавливать не надо,
всё через сайт github.com.


ШАГ 1. СОЗДАТЬ РЕПОЗИТОРИЙ
--------------------------
github.com -> New repository.
Имя: rok-gruppa
Public. Галочку "Add a README file" НЕ ставить.
Create repository.

ВАЖНО: если назовёшь репозиторий не rok-gruppa, то открой файл
vite.config.ts и поменяй там строку

    base: '/rok-gruppa/',

на имя своего репозитория. Иначе сайт откроется пустым белым экраном.


ШАГ 2. ЗАЛИТЬ ФАЙЛЫ
-------------------
Распакуй архив. Внутри папка rok-gruppa, в ней файлы и папки:

    src, index.html, package.json, package-lock.json,
    vite.config.ts, tsconfig.json, tsconfig.app.json,
    tsconfig.node.json, README.md

На странице репозитория: Add file -> Upload files.
Перетащи МЫШЬЮ все эти файлы и папку src.
Внизу нажми Commit changes.

ПРОВЕРЬ: package.json должен лежать прямо в корне репозитория,
а не внутри ещё одной папки rok-gruppa. Если он оказался внутри
папки, сборка не найдёт его и упадёт.


ШАГ 3. ВКЛЮЧИТЬ PAGES
---------------------
Settings -> слева Pages -> Source выбрать GitHub Actions
(НЕ "Deploy from a branch").


ШАГ 4. ДОБАВИТЬ ФАЙЛ СБОРКИ (самое важное место)
------------------------------------------------
Файлы, имя которых начинается с точки, через перетаскивание мышью
НЕ ЗАГРУЖАЮТСЯ - GitHub их молча выбрасывает. Поэтому папку .github
надо создать руками. Это проверено, не пропускай.

На главной странице репозитория: Add file -> Create new file.
В строке имени файла напиши ровно это (косые черты создадут папки сами):

    .github/workflows/deploy.yml

В большое поле ниже скопируй ВСЁ содержимое файла
.github/workflows/deploy.yml из архива.
(Если в распакованной папке его не видно - включи показ скрытых файлов:
в Проводнике вкладка "Вид" -> галочка "Скрытые элементы".)

Нажми Commit changes.

Этот файл добавляй ПОСЛЕДНИМ. Тогда сборка запустится ровно один раз,
а не на каждую заливку.


ШАГ 5. ДОЖДАТЬСЯ СБОРКИ
-----------------------
Вкладка Actions - там появится запуск "Deploy to GitHub Pages".
Идёт 1-2 минуты. Зелёная галочка - готово.
Адрес сайта: Settings -> Pages, сверху ссылка вида

    https://ТВОЙ-ЛОГИН.github.io/rok-gruppa/

Эту ссылку и сдавать.


ШАГ 6. ПРОВЕРИТЬ, ЧТО РАБОТАЕТ
------------------------------
Открой ссылку и пройди по порядку:
  1. вкладка "Регистрация", придумай логин и пароль (от 6 символов)
     -> должен открыться кабинет;
  2. заполни имя, выбери инструмент, напиши пару слов о себе,
     поставь ставку -> "Сохранить" -> появится зелёное "Сохранено.";
  3. нажми "Выйти" -> вернутся формы;
  4. войди тем же логином -> данные должны остаться на месте.

Если всё это прошло - работа сдана.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------
Белый пустой экран
    Имя репозитория не совпадает со строкой base в vite.config.ts.

Во вкладке Actions пусто, сборка не началась
    Не загрузился файл .github/workflows/deploy.yml (шаг 4) или
    в Settings -> Pages не выбран GitHub Actions (шаг 3).

Сборка падает на первом шаге
    package.json лежит не в корне, а внутри лишней папки.

На сайте пишет "Учетные данные не были предоставлены"
    Это ответ сервера для тех, кто не вошёл. Просто войди заново.
